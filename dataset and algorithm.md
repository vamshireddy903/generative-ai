#  What is a Dataset?

A dataset is a collection of data used to train or test an AI model.

Simple Definition

A dataset is the information that an AI learns from.

**More Dataset Examples**  

- Millions of cat and dog images
  
- Customer purchase history  
- Medical records  
- Weather data  
- Text from books and websites  
- GitHub code repositories

# 2. What is an Algorithm?

An algorithm is a step-by-step method or set of rules used to solve a problem or learn from data.

Simple Definition

An algorithm is the method that teaches the computer how to learn from a dataset.

Think of it as the recipe for learning.

AI Example

Suppose you have:

100,000 spam emails (dataset)

You choose an algorithm such as:

- Decision Tree  
- Random Forest  
- Neural Network  

The algorithm studies the dataset and learns patterns.

The result is a trained model.
