# AI
Artificial Intelligence (AI) is the field of computer science focused on creating systems that can perform tasks that normally require human intelligence.

**These tasks include:**

- 🧠 Learning from data  
- 💡 Solving problems  
- 🗣️ Understanding and generating language  
- 👀 Recognizing images and videos  
- 🎤 Understanding speech  
- 🤖 Making decisions  

Simple Definition

Artificial Intelligence is the ability of a computer or machine to think, learn, and make decisions in a way that resembles human intelligence.

# Everyday Examples of AI

**ChatGPT** – Understands your questions and generates responses.  
**Google Maps** – Suggests the fastest route based on traffic.  
**Netflix/YouTube** – Recommends movies and videos you might like.  
**Amazon** – Suggests products based on your shopping history.  
**Spam filters** – Detect unwanted emails.  
**Voice assistants** – Apple's Siri, Google Assistant, and Amazon Alexa understand voice commands.  

How AI Works

AI systems generally follow these steps:

**Collect data** (text, images, videos, sensor data, etc.)  
**Learn patterns** from the data using algorithms.  
**Make predictions** or decisions based on what they learned.  
**Improve over time** as they receive more data and feedback.

# 1. Generative AI

Generative AI is designed to create new content based on the data it has learned from.

**Examples**

- Writing emails  
- Creating images  
- Generating code  
- Summarizing documents  
- Translating languages

**Example**

Prompt:

     Write a Python script to upload a file to AWS S3.

Generative AI Response:  
 
It generates the Python code.

Once the code is generated, its job is complete.

# 2. Agentic AI

Agentic AI is designed to complete an objective, not just generate content.

It can:

- Understand the goal  
- Break it into smaller tasks  
- Decide what to do next   
- Use tools or APIs  
- Check results  
- Retry if something fails  
- Continue until the goal is achieved

**Example**

Goal:

Deploy my application to Kubernetes.

An Agentic AI might:

- Check whether Docker is installed.  
- Build the Docker image.  
- Push it to a container registry.  
- Create Kubernetes manifests.  
- Apply them with kubectl.  
- Verify that the pods are running.  
- If a pod fails, inspect the logs.  
- Fix the issue and redeploy.  

Instead of only generating YAML files, it actively works toward completing the deployment.
